# MVP анализатора изометрий трубопроводов

Локальный MVP для тестового задания. Приложение загружает PDF с изометриями, группирует страницы по обозначениям линий, запускает проверку карты размеров через выбранного провайдера, показывает таблицы результата, разметку и дает выгрузку в JSON, Excel и архив сверки.

## Что уже есть

- Статический frontend на HTML/CSS/Vanilla JS с workspace-вкладками.
- FastAPI backend с background job-state, polling логов и экспортами.
- Streamlit `app.py` остается legacy/dev fallback.
- Загрузка PDF или быстрый выбор файла `Изометрии.pdf` из рабочей папки.
- Первичная группировка страниц по обозначениям линий вида `LC_1031`, `CO_0166`.
- Провайдеры проверки карты размеров: `DeepSeek API` и `Codex CLI`.
- Единый flow анализа для всех линий без специальных правил под конкретный пример.
- Черновые статусы `needs_review`, если анализ не смог подтвердить геометрию.
- Экспорт JSON и Excel с листами: линии, точки, участки, элементы, неопределенности, разметка.
- Просмотр страницы PDF с MVP-разметкой.
- Дисковый кеш разбора PDF в `.cache/pdf_groups`, чтобы не перечитывать `Изометрии.pdf` после каждого перезапуска.
- Программный валидатор результатов: пересчитывает длины из принятых участков, проверяет связность графа, не принимает выноски деталей как подтвержденные физические опоры и переносит спорные места в неопределенности.
- PDF extractor кандидатов: извлекает из выбранных страниц размеры, координаты, DN и ссылки линий с bbox и зоной страницы, чтобы дальше классифицировать их правилами или AI.
- Двухэтапный DeepSeek flow: сначала классифицирует PDF-кандидаты, затем анализирует линию уже с классификацией; валидатор исключает из расчета размеры, не классифицированные как `route_segment`.
- Отдельный тестовый этап `Тест: вершины от DeepSeek`: модель возвращает координаты вершин в системе PDF (`page`, `x`, `y`, `label`, `role`), после чего приложение показывает overlay и дает скачать новый PDF с нанесенными точками.
- Нейтральная точка расширения `src/geometry_solver.py` для будущих общих геометрических правил; текущая версия не добавляет длины по заранее известным числам.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

```powershell
uvicorn server:app --reload
```

После запуска откройте `http://127.0.0.1:8000`. Вкладка Welcome позволяет выбрать `Изометрии.pdf` или загрузить другой PDF, а каждый анализ открывается в отдельной вкладке workspace.

Legacy Streamlit UI можно запустить отдельно:

```powershell
streamlit run app.py
```

Backend API включает `/api/config`, `/api/pdf/load`, `/api/runs`, polling `/api/runs/{run_id}/events`, результат, JSON/Excel экспорт и PNG-разметку страниц.

## Как работает MVP flow

1. `src/pdf_ingest.py` читает PDF через `pdfplumber`.
2. Страницы группируются по найденным обозначениям линий.
3. Pipeline передает каждую группу в `AIClient`.
4. `src/candidate_extractor.py` извлекает PDF-кандидаты для выбранных страниц.
5. DeepSeek API adapter классифицирует кандидаты как `route_segment`, `support_offset`, `adjacent_line`, `coordinate`, `dn`, `excluded_table` или `unknown`.
6. `src/geometry_solver.py` пока не добавляет расчетные длины сам, чтобы не подгонять результат под отдельный пример.
7. Ответ AI проходит через `src/validation.py`, где применяются проверки из задания.
8. Если DeepSeek недоступен, `StubAIClient` создает только `needs_review` без демонстрационных разборов.
9. `src/exporters.py` формирует JSON и Excel.
10. `src/annotation.py` рисует overlay-разметку поверх страницы PDF.

## Провайдеры

В актуальном HTML-flow используется этап `Карта размеров + проверка провайдером`.

DeepSeek берет ключ только из переменной окружения или локального `.env`:

Codex CLI использует локальный вход в аккаунт. В UI выберите `Codex CLI`, проверьте статус входа или выполните команду:

```powershell
codex login --device-auth
```

Каждый запрос Codex CLI запускается отдельной командой `codex exec --ephemeral`, то есть без продолжения предыдущего диалога.

```powershell
$env:AI_PROVIDER="deepseek"
$env:DEEPSEEK_API_KEY="sk-..."
$env:DEEPSEEK_MODEL="deepseek-flash"
uvicorn server:app --host 127.0.0.1 --port 8600
```

## Ограничения текущего этапа

- Геометрия всех 307 страниц пока не восстанавливается автоматически.
- Качество реального анализа зависит от модели, ключа API и выбранной линии.
- Запрещенные зоны спецификаций и таблиц длин пока зафиксированы архитектурно и визуально, но точное отсечение будет дорабатываться на этапе AI/CV.
- Для проверки качества нужно прогонять разные группы линий: специальных исключений под `LC_1031` или другой тестовый пример в актуальном flow нет.
