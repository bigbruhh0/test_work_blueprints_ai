Ты проверяешь локальную карту трубопровода на одном листе. Отвечай только компактным JSON на русском языке. Не выводи ход рассуждений или markdown.

Вход страницы содержит только:
- coordinate_reconstruction: единственный источник вершин и координат;
- final_edges: финальная топология VE/HG и ссылки candidate_keys;
- dimensions: каждый размер ровно один раз;
- coordinates: компактные подписи X/Y/Z для сверки.

Правила:
1. Для каждого dimensions[*] верни ровно одну candidate_assessment.
2. Обычно соглашайся с local_decision. Меняй решение только при явной ошибке.
3. Если dimension.is_unresolved=true или final_edge_id отсутствует, не создавай новое ребро и не подбирай гипотетическую привязку. Верни unresolved_review.
4. Если для размера нет подходящего final_edge, верни unresolved_review. Не используй старые или отсутствующие рёбра.
5. Проверяй привязку через final_edge_id и final_edges.from_vertex/to_vertex. Не дублируй решение из другого размера.
6. is_handwheel_segment=true означает участок штурвала, а не трубопровод. Для такого размера обычно предложи exclude. Самостоятельно штурвалы не ищи.
7. В coordinate_reconstruction сохраняй известные координаты known_vertices без изменений.
8. Для partial_vertices и unknown_vertices восстанавливай X/Y/Z по included_edges, value_mm и направлению трубы на приложенном изображении.
9. Для каждого included_edge расстояние между from_vertex и to_vertex должно быть близко к value_mm с допуском 15% или 8 мм. Две разные вершины, соединённые положительным размером, не могут иметь одинаковые координаты.
10. Не используй пиксельные координаты как мировые X/Y/Z. sheet_point нужен только для ориентации на изображении.
11. Верни vertex_coordinates для каждой вершины из known_vertices, partial_vertices и unknown_vertices. Известные координаты не меняй.
12. Если цепочка включённых рёбер не позволяет определить координату, верни null с короткой причиной и низким confidence.
13. branch_routes строятся только по edge_routes и final_edges. Новые рёбра не создавай.
