Ты проверяешь локальную карту размеров трубопровода по одному листу. Отвечай только компактным JSON. Все reason/name пиши на русском.
Не рассуждай пошагово. Не выводи markdown. reason должен быть коротким.

Вход уже содержит финальную локальную геометрию:
- final_vertices / vertices: финальные вершины VE-* и HG-*.
- final_edges / edges: финальные отрезки F-* между VE/HG.
- dimensions: все размерные кандидаты, уже привязанные к final_edge_id или помеченные unresolved.
- unresolved_dimensions: кандидаты, которые локально не удалось уверенно посадить на F-*.
- coordinates: найденные координатные подписи X/Y/Z/Z+ на листе.
- cross_sheet_text_refs: только явные ссылки со словом ЛИСТ.

Твои задачи:
1. Для каждого dimensions[*] верни ровно одну candidate_assessment.
2. Обычно соглашайся с local_decision. Меняй его только при явной ошибке: вложенный/дублирующий размер, размер штурвала, размер смежного листа, явное несоответствие final_edge_id.
3. Если assessment="accepted", proposed_decision должен быть null.
4. Если не согласен, assessment="disputed" и proposed_decision="include|exclude|ambiguous".
5. Если данных недостаточно, assessment="insufficient" и proposed_decision="ambiguous".
6. Для unresolved_dimensions верни unresolved_reviews: почему размер не попал на отрезок и что проверить.
7. Размер штурвала определяй по final_edge.is_handwheel_segment, handwheels, HG-* и выносным линиям. В reason обязательно напиши "размер штурвала". Если такой размер не должен входить в длину трубы, предложи exclude.
8. Найди ссылки на другой лист только если в тексте есть слово "ЛИСТ" и номер. Одиночное "СМ." без "ЛИСТ" игнорируй. Для явных ссылок заполни cross_sheet_links и при наличии числовой длины intermediate_distances kind="adjacent_sheet_length".
9. Классифицируй final_edges как main/branch/handwheel/unknown. Не используй debug_source_edges для решений, они только для справки.
10. Для каждого final_vertices[*] верни одну vertex_coordinates. Если X/Y/Z можно надежно взять из coordinates или вывести из явных координатных подписей и размеров, заполни. Если нет, оставь x/y/z=null, confidence=0, method="не определено", reason кратко.
11. Не восстанавливай длины по пикселям, радиусам и геометрии. Длины считаются только по явно нанесенным размерам.

ID:
- candidate_id используй как во входе: candidate_key, например "216:D001".
- edge_id используй как во входе: edge_key или final_edge_id, например "216:F-VE-07-HG-03-A".
- vertex_id в vertex_coordinates используй локальный ID "VE-07" или "HG-03-A"; vertex_key используй "216:VE-07".
